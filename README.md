# Nani

Nani is a small flashcard app for learning the basic Japanese hiragana set. It uses large kana cards, romanized pronunciation, browser-based audio, and short visual mnemonics to make review quick and memorable.

The app is built with Vite, React, TypeScript, Tailwind CSS, and TanStack Router.

## Features

- Start screen with Nani branding and a custom logo
- SVG favicon and PNG app icon assets
- TanStack Router navigation with virtual file routes
- Home route, practice route, and full hiragana chart route
- Randomized practice deck with 46 basic hiragana
- Large tap-to-reveal flashcards
- Romaji answer for each kana
- Pronunciation guidance for each kana
- Browser-based Japanese audio playback using the Web Speech API
- Automatic audio playback when the answer is revealed
- Replay button to hear the kana again
- Volume reminder before and during practice
- Original mnemonic hints and visual cues
- Progress bar with percentage text
- Known, review, and remaining counters
- Restart and practice-again flows
- Responsive layout for desktop and mobile
- Pointer cursor on clickable controls

## Requirements

- Node.js 18 or newer
- npm 9 or newer

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will print a local URL in the terminal. Open that URL in your browser to use the app.

## Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Routes

Nani uses TanStack Router with virtual file routes. The virtual route tree is defined in `routes.ts` and points to real route files in `src/routes`.

Current routes:

- `/`: Home page with app branding and start action
- `/practice`: Flashcard practice flow
- `/hiragana`: Complete hiragana chart with pronunciation and mnemonics

The generated route tree lives in `src/routeTree.gen.ts`. It is produced by the TanStack Router Vite plugin and is used by `src/main.tsx` to create the router.

## Audio behavior

Nani uses the browser's built-in Web Speech API with Japanese language utterances. This keeps the project lightweight because it does not need bundled audio files.

Audio support and voice quality depend on the browser, operating system, and installed system voices. Chrome, Edge, and Safari usually provide the best support. Users should increase their device volume before starting practice.

## Customizing the deck

The hiragana data lives in `src/data/hiragana.ts` in the `hiraganaCards` array. Each card includes:

- `kana`: The hiragana character
- `romaji`: The romanized answer
- `row`: The kana row key, used for grouping
- `rowLabel`: The display label for the row
- `pronunciation`: A short pronunciation guide
- `mnemonic`: A short memory hint
- `visualCue`: A small visual cue shown after reveal and on the chart page

To add more kana, extend this array with new card objects.

## Notes

The mnemonic text and learning prompts are original. They are inspired by playful visual learning methods, but they are not copied from any third-party app.

This project does not include external audio files. Pronunciation is generated by the user's browser.
